## DeepSeek++ 1.15.0

1.15.0 跟进 DeepSeek 官网「模式合并 + 附件升级」改版，并补齐侧边栏的对话模式开关与官网会话共享。

官网已把快速 / 专家 / 识图三种模式合并为单一模型，输入框改为「深度思考」「智能搜索」两个开关，附件从仅图片放开为文档、代码、表格等多类文件。本版本让扩展与线上行为对齐。

### 主要变化

- **模型类型收敛**：`expert` / `vision` / `reasoner` 等全部别名统一归一为 `default`（线上唯一仍可用的模型值），模式意图改由 `thinking_enabled` / `search_enabled` 承载。
- **侧边栏对话模式开关**：网页对话新增「深度思考」「联网搜索」两个开关，与官网输入框开关同义；开启联网时扩展自带的 `web_search` / `web_fetch` 会从模型可见工具目录中移除，把联网交给 DeepSeek 页面原生搜索，避免两个搜索器并存。
- **附件上传对齐官网**：以官网运行时配置为唯一真源派生可接受扩展名与大小上限，不再硬编码 `image/*` + 8 MiB；配置缺失、schema 不认识或字段非法时 fail-closed 回退到已发布限制并记录原因。侧边栏附件支持非图片文件（渲染为文件占位而非缩略图）。
- **官网会话浏览与绑定**：侧边栏可列出官网账号的会话，选择一个绑定后，侧边栏消息直接进入该会话（复用其会话链并解析续跑叶子节点），官网页面刷新即可看到。仅保存会话引用，不保存消息内容。
- **设置页精简**：移除已失效的「默认 / 专家 / 识图」三选一，改为说明文案。
- **输入框定位修复**：官网移除了 `#chat-input` id，改按页面占位文案识别输入框；页面出现多个 textarea 时不再静默选中错误的那个。
- **主题联动**：官网深色标记迁移为 `body` 的 `light` / `dark` class，扩展同步跟进（保留旧版 `data-ds-dark-theme` 兜底）。
- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。

### 修复

- 修复侧边栏网页对话把 `thinking_enabled` / `search_enabled` 硬编码为 `false`、导致无法启用深度思考与联网的问题。
- 修复连续切换两个开关时「读-改-写」丢更新（后一次写入覆盖前一次）的问题，改为 store-local 串行队列。

### 已知限制

- 侧边栏上传上限为 24 MiB，低于官网自身的 100 MiB：侧边栏以单条 base64 runtime 消息传输文件，100 MiB 在该通道上不可行。超过该上限时提示改用 DeepSeek 页面输入框上传。
- 会话共享为「共享会话目标」：侧边栏与官网页面指向同一会话，但不会自动刷新官网页面，也不做官网到侧边栏的实时镜像。
