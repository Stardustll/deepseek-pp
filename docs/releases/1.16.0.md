## DeepSeek++ 1.16.0

1.16.0 是侧边栏对话体验版本：模式开关改为官网样式、对话记录本地保留并可查看删除、助手回答的 Markdown 完整渲染。同时移除了一项有账号风险的功能。

### 主要变化

- **模式开关改用官网样式**：侧边栏的「深度思考」「联网搜索」按官网输入框开关的规格重做（34px 高、18px 圆角、13px/500，选中态使用官网的 deepseek 色阶），并收进输入框左下角的设置按钮内，点击展开。
- **本地对话记录**：侧边栏对话自动保存在本机，刷新或重开侧边栏都会恢复。左下角历史按钮可列出本地对话（标题取首条消息、显示消息数），支持打开切换、单条删除、清空全部；删除操作只影响本机，不影响 DeepSeek 账号。
- **记住上次所在标签页**：侧边栏重开后回到上次的位置，不再总是跳回「对话」。
- **助手回答的 Markdown 完整渲染**：修复此前表格、删除线、任务列表完全不解析的问题（缺 GFM 支持），并用主题样式取代了未生效的 typography 类，标题层级、列表、引用、代码块、表格、链接现在都有正确样式，浅色与深色均适用。
- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。

### 移除

- **官网会话读取与绑定已移除**。从扩展侧列出、读取或续接官网账号里的会话，等于在用户账号上做出超出其页面操作的行为，存在被判定异常而封禁的风险，因此整条移除（含相关运行时命令与存储键）。对话连续性改由本地记录提供。

### 修复

- 修复模式弹层在输入框内按 Escape 不关闭的问题。
- 修复「新建会话」会静默解除会话绑定的问题（该功能现已移除）。
- 修复重开侧边栏丢失上次本地记录、以及回合失败时用户输入不落盘的问题。
- 修复会话记录连续写入时的丢失更新（改为 store-local 串行队列）。
