## DeepSeek++ 1.16.1

1.16.1 是发布流程修复版本：Shell Host 的 npm 包改用本账号的 scoped 名，并把发布认证从长期 token 换成 OIDC trusted publishing。

### 主要变化

- **Shell Host 包改名**：`deepseek-pp-shell-host` → `@tflystar/deepseek-pp-shell-host`。原名已被其他维护者占用，无法在自己的账号下发布；作用域由本人独占，不会再撞名。安装命令变为：

  ```bash
  npx @tflystar/deepseek-pp-shell-host install --browser chrome --extension-id <扩展ID>
  ```

  可执行文件名仍是 `deepseek-pp-shell-host`，已安装用户的命令与 PATH 不受影响。

- **发布改用 OIDC trusted publishing**：仓库不再保存任何长期 npm 写权限 token，每次发布使用短时签名凭据。需要在 npm 包设置里配置 Trusted Publisher 指向本仓库的 `release.yml`。

- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。

### 修复

- 修复 npm 发布流程在 Node 22 下必然失败的问题：trusted publishing 要求 npm CLI ≥ 11.5.1，而 Node 22 自带 npm 10.x，现在工作流会显式升级并在版本不足时报错，而不是静默回退到 token 认证。
- 修复富文本渲染分片的 gzip 上限缺少编码器差异容忍导致的偶发失败（实测仅差 1 字节）。
